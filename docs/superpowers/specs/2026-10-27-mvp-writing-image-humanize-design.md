# MVP 优化设计：写作 → 配图 → 人味

- 日期：2026-10-27
- 产品：AIWriteX（开源树）
- 策略：精简可落地 MVP（路径 B：流水线增强）
- 交付顺序：一期写作 → 二期配图 → 三期人味
- 状态：一期/二期/三期 MVP 已实现（待真实 LLM 链路人工验收）

## 1. 背景与目标

开源主链路已具备：单 writer 生成 Markdown → 可选维度创意 → 模板/AI 设计 HTML → 保存 →（可选）微信发布。  
主要短板：成稿结构弱、配图多为 picsum 占位且无语义策略、无人味化后处理。

**MVP 成功标准**：稳定产出「能发公众号的图文」——有结构与钩子、字数可控、有封面与文内图、基础降低模板感。不做朱雀对抗、不做 README 全量能力对齐。

## 2. 约束

- 在现有 `UnifiedContentWorkflow` 上增量扩展，不大改多智能体框架。
- 不依赖商业版完整 `tools/`；缺能力时用最小桩或现有工具，缺什么补什么。
- 微信为主发布目标；其他平台适配器本轮不扩展真实发布。
- 配置可开关；默认开启一期写作增强，二三期可默认开启但允许关闭。
- 本仓库用户规则：未经明确要求不自动 git commit。

## 3. 总体架构

最终主流程：

```
选题
  → [一期] 大纲 → 成稿 → 轻质检（可局部重写 1 次）
  → (可选) 维度化创意（保持现有）
  → [三期] 人味后处理
  → [二期] 封面 + 文内配图
  → 模板填充 / AI 设计 HTML
  → 保存 → (可选) 发布
```

说明：实现顺序仍是「写作 → 配图 → 人味」；挂到主流程时，人味放在配图前，避免对已插图 HTML 做破坏性改写。一期上线时二三期节点为空实现或透传。

### 3.1 模块边界

| 模块 | 职责 | 主要依赖 |
|------|------|----------|
| `core/writing/` | 大纲、成稿、质检编排与提示词 | `ContentGenerationEngine`、`Config` |
| `core/imaging/`（二期） | 封面生成/裁剪、文内插点与图源 | `img_api`、`crop_cover_image`、文章 HTML/MD |
| `core/humanize/`（三期） | 规则后处理 + 可选 LLM 润色 | Markdown 文本、`Config` |
| `unified_workflow.py` | 串联阶段、进度日志、开关 | 上述模块 |

各阶段输入输出统一为：`ContentResult`（title/content/summary）或明确的中间 DTO（如 `OutlineResult`），避免隐式字符串约定。

## 4. 一期：写作质量

### 4.1 目标

同一话题下，成稿结构与开头质量明显高于「单 writer 一把梭」。

### 4.2 流程

1. **Outline（短任务）**  
   - 输出：3 个候选标题（选 1）、开头钩子类型、3～6 个小标题大纲、目标字数区间。  
   - 钩子类型内置 5～8 种（如反常识、痛点提问、数据冲击、场景代入、对比反差等），不做「文案武库」全量场景库。

2. **Write**  
   - 严格按大纲写标准 Markdown。  
   - 保留现有 `aiforge_search_tool` / `urls` / `reference_ratio` 行为（工具可用则用；不可用时降级为无搜索写作并打日志）。

3. **QC**  
   - 规则检查：字数是否在 `min_article_len`～`max_article_len`；是否有标题；开头是否过短/空泛；列表块是否过多。  
   - 不达标：带「失败原因」局部重写 **最多 1 次**；仍不达标则保留最好一版并标记 warning，不阻断保存。

### 4.3 配置（建议键名）

```yaml
writing:
  outline_enabled: true
  hooks_enabled: true
  qc_enabled: true
  qc_max_rewrite: 1
```

### 4.4 进度协议

新增内部日志：`[PROGRESS:OUTLINE:START|END]`、`[PROGRESS:WRITING:...]`（沿用）、`[PROGRESS:QC:START|END]`。前端进度条可后续映射；一期至少保证日志可观测。

### 4.5 验收

固定 3 个自定义话题各生成 1 篇：人工判定「有清晰小标题结构、有明确开头钩子、字数合格」通过 ≥ 2/3。

### 4.6 写作前素材收集（自定义题目搜索优化）

问题：自定义题目原样作为搜索词，结果不做相关性判断，且提示词要求「基于搜索结果写作」，无关素材会污染成稿。

方案（`core/research/`）：
1. 搜索从写作智能体的工具调用中移出，由流水线在大纲之前直接执行；写作智能体不再挂搜索工具。
2. 搜索词改写：一次模型调用把题目改成 2～3 个检索关键词；失败时用规则去掉口语成分。
3. 相关性筛选：题目/搜索词的中文两字片段在结果标题+摘要中的覆盖率，取最大值，低于阈值丢弃；可选再加模型判断。
4. 全部不相关时视为无素材，原创写作；提示词明确「无关素材必须忽略、不要编造数据」。
5. 参考链接模式不做相关性筛选（用户主动指定）。

```yaml
research:
  mode: auto              # auto | always | off
  llm_query_rewrite: true
  llm_relevance_check: false
  relevance_threshold: 0.25
  max_materials: 8
```

### 4.7 明确不做（一期）

完整研究员/审核员多 Agent 链；专家赛道完整体系；文案武库 24 场景与五旋钮。

## 5. 二期：配图

### 5.1 目标

自动封面 + 文内 2～4 张图；预览路径可见；不依赖「完美生图」。

### 5.2 策略

1. **封面**  
   - 根据标题/主题取图：`img_api.ali` 可用则生图，否则 picsum / 本地占位。  
   - 复用已有 `crop_cover_image`（900×384），路径写入文章 sidecar（`.design.json` 的 `cover` 字段，与现有读取逻辑对齐）。

2. **文内图**  
   - 按 H2 / 段落切点选插入位置。  
   - 规则：文首不插图；相邻图至少间隔 1 段；总图数落在配置区间（默认 2～4）。

3. **模板路径**  
   - 填充或设计阶段：将模板中的 picsum 占位替换为本次生成图或带语义 alt 的本地图，而不是仅「保持位置」。

### 5.3 配置（建议）

```yaml
image:
  cover_enabled: true
  inline_enabled: true
  inline_min: 2
  inline_max: 4
```

### 5.4 验收

预览 HTML 能解析到封面；正文图片数量在配置区间；外链失败时有本地兜底，不出现大片裂图。

### 5.5 明确不做（二期）

16 种图片赛道、资源图库/Prompt 中心/生图实验室完整产品面。

## 6. 三期：基础人味

### 6.1 目标

降低一眼 AI 的模板感；强度可配；可一键关闭。

### 6.2 流水线（对 Markdown 成稿）

1. 过长列表 → 段落化  
2. 段落长短交错（合并过碎段 / 拆过长段，轻度）  
3. 弱化高频连接词（首先/其次/综上所述等）  
4. 可选：低强度口语化 / 主观句注入  
5. 可选：一轮 LLM「人味润色」（默认关或低优先级，可配置）

### 6.3 配置（建议）

```yaml
humanize:
  enabled: true
  intensity: low   # low | medium
  llm_polish: false
```

### 6.4 验收

同文处理前后：列表密度与连接词频次下降；开关关闭时输出与处理前一致。

### 6.5 明确不做（三期）

朱雀评分闭环、风格 DNA 拟态全套、对抗检测军备。

## 7. 错误处理

- 大纲失败：回退为「无大纲直接写作」，打 warning。  
- 搜索工具缺失/失败：按现有提示词降级原创写作，不中断。  
- 质检重写失败：保留原稿 + warning。  
- 配图失败：跳过该图并用占位或少图策略，不阻断保存。  
- 人味处理异常：透传原文。

## 8. 测试策略

- 单元：QC 规则、插图位置选择、人味规则变换（纯函数优先）。  
- 冒烟：`writing.outline_enabled` 开关开/关各跑一条生成链路（可用 mock LLM/工具）。  
- 人工：每期按验收标准抽检 3 篇。

## 9. 实现顺序与计划边界

1. 先写**一期写作**实现计划并开发、验收。  
2. 再写二期配图计划并开发。  
3. 最后三期人味。  

每期独立可合并；主流程对未实现阶段透传，避免半成品耦合。

## 10. 已确认决策摘要

- 产品方向：B 精简 MVP  
- 路径：流水线增强，非大改多智能体、非只改提示词  
- 顺序：写作 → 配图 → 人味  
- 一期范围：大纲 + 成稿 + 轻质检（最多重写 1 次）
